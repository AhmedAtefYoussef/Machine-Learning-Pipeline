# ADR-017 Second pass: target = power transform of cnt + 1 with exponent 0.1 (supersedes the transform of ADR-001)
status: accepted        phase: p1 (whole chain re-run)        owner: chief
context: the first complete run (tag v1-submitted) fitted log1p(cnt). A diagnostic showed that fitting on the bike scale gains R2 (exp/loss_scale/diag.json), i.e. the log weights quiet night hours too heavily for a score computed on bikes. The question was whether that gain is available inside ordinary linear regression, so that every phase stays a course algorithm.
options: keep log1p / power family z = ((cnt+1)^lam - 1)/lam, lam chosen once / observation weights / a bike-scale loss with log link in every phase or as a final refit
evidence: exp/v2/e1_target.json, e3_ceiling.json, e4_weights.json (closed-form fits; seeded / held-out days / chronological). Target design: lam 0 0.9390 / 0.9426 / 0.9141; lam 0.05 0.9410 / 0.9453 / 0.9297; lam 0.1 0.9413 / 0.9462 / 0.9378; lam 0.15 0.9405 / 0.9459 / 0.9411; lam 0.2 0.9389 / 0.9448 / 0.9411; lam 0.5 0.9231 / 0.9310 / 0.9148. Gain of 0.1 over the log on held-out days +0.0036 (paired se 0.0005, 5 of 5 folds), chronological +0.024. The best exponent falls as the model grows: Phase 1 design 0.25-0.3, Phase 2 design 0.1-0.2, target design 0.1. The ladder under lam 0.1 still selects C6 by the Phase 3 rule.
decision: lam = 0.1, set in config (p1.target_power) and fixed for the whole chain. It is chosen for the model the chain ends with, from the first pass and these pilots, not from Phase 1's own validation score; Phase 1 shows its exponent table for transparency and Phase 3 re-checks the exponent on the target design (the chain is consistent only if that check agrees with 0.1 within the 0.001 tolerance). Back-transform candidates become none / least-squares factor (Duan's factor is defined for the log only). The bonus loss keeps its definition on bikes with the new inverse transform.
consequences: all artifacts, the notebook, the report and the submission change; second-pass Expectation cells are committed before the re-run and the original ones stay untouched. Rejected alternatives are in ADR-018.
