# ADR-016 Survivors: L1 selection is run after the redundant columns are removed (supersedes the order in ADR-011)
status: accepted        phase: p4        owner: chief
context: ADR-011 took the Lasso zeros from the full candidate design and then removed features of non-useful columns. In the rebuild after ADR-015 this order cost robustness: with month dummies, season dummies, `yr` and `instant` in the design, Lasso kept only 3 of the 5 `dteday` features (the copies stood in for the rest); the verdict step then removed the copies as redundant, so the surviving set had lost part of the season/trend description twice.
options: keep the order / select with L1 on the design restricted to useful columns
evidence: artifacts/p4.json of that rebuild (commit "rebuild after improvement round 1"). Phase 3 target without candidates: chronological R2 0.914. Stage-B models on the survivors: 0.901 for all three methods, with validation (0.9386 vs 0.9390) and held-out days (0.9424 vs 0.9426) hardly moved. Lasso kept 3 of 5 dteday features and 9 of 11 month dummies.
decision: order is now (1) stage A: three methods on the full candidate design, (2) verdicts from drop tests with the Lasso evidence of stage A as support, (3) selection: Lasso path and 50-resample stability selection on the design restricted to features whose source columns are all useful; survivors = non-zero at its validation-chosen λ and selection frequency ≥ 0.6, (4) stage B: the three methods on the survivors, recommendation rule of ADR-010.
consequences: "the feature subset L1 leaves non-zero" is computed where L1 is not choosing between copies; one more Lasso path and stability run in Phase 4.
