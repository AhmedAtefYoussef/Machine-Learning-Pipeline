## 1 The transform (src/common.py)
`@dataclass(frozen=True) class Target: power: float; back_method: str` with
- `forward(cnt) -> z`: `log1p(cnt)` if power == 0 else `((cnt + 1)**power - 1) / power`
- `q(eta) -> cnt + 1 on the bike scale`: `exp(eta)` if power == 0 else `maximum(power*eta + 1, 1e-9) ** (1/power)`
- `factor(eta_train, cnt_train) -> s`: "none" → 1.0; "ls" → Σ(cnt+1)·q / Σ q²; "duan" → mean(exp(z − eta)), valid for power == 0 only (raise ValueError otherwise)
- `to_bikes(eta, s) -> cnt_hat = clip(s·q(eta) − 1, 0, None)`
- `dq_deta(eta)`: `q(eta) ** (1 − power)` (needed by the bonus gradient; for power 0 it is q itself)
- `eta_cap(cnt_train)`: the eta at which q = e·(max(cnt_train) + 1), i.e. `forward(e·(max+1) − 1)`; for power 0 this equals the old cap `max(z) + 1` exactly.
- `to_dict()` / `Target.from_artifact(p1)` reading `p1["target_power"]` and `p1["backtransform"]["method"]`.
Keep `to_target`, `back_factor`, `from_target` as thin wrappers ONLY if still used; prefer replacing every call by the Target methods and deleting the old functions (update tests accordingly). Every module that now takes `back_method: str` takes `target: Target` instead (p3 Context, p4 Context and helpers, validation.* signatures, predict). No module-level mutable state.
With `power == 0` and method "ls" every phase must reproduce the v1 numbers (see acceptance A).
