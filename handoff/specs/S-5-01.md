## src/labels.py
`fit_thresholds(train_df, group_by, quantile) -> DataFrame[group_by + ["threshold", "n"]]` (pandas quantile, linear interpolation; `group_by = []` → one global row) · `apply_thresholds(df, table, group_by) -> np.ndarray[int]` label = 1 if cnt > threshold of the row's cell (lookup; a cell missing from the table → raise). Thresholds are always fitted on the training frame.

## src/phases/p5.py (`run(cfg=None)`, step functions; sklearn must not be imported)
1. `p4 = read_artifact("p4")`; split; `design = Design(DesignSpec.from_dict(p4["design_spec"])).fit(train_df)`; survivor column indices from `p4["survivors_expanded"]` (assert all found) → X_tr, X_va = bias + survivor columns only. `features` (chain_check key) = the survivor names used (no "bias"). Assert set(features) ⊆ set(p4.survivors_expanded).
2. label rule from cfg.p5 (group_by, quantile): thresholds on train_df → y_tr, y_va. `threshold_rule` (chain_check key) = `{quantile, group_by, fitted_on: "train", n_cells, min_cell_n, table}`. `class_balance = {train, val, val_by_year: {"0": …, "1": …}, majority_accuracy}`.
3. model selection: for l2 in cfg.p5.l2_candidates: `fit_logistic(X_tr, y_tr, l2=l2, max_iter=cfg.p5.max_iter)` → `{l2, iterations, stop_reason, train_logloss, val_logloss, val_roc_auc}`; choose max val_roc_auc (tie within 1e-4 → larger l2). gradient check of the log-loss at zeros and at the final weights (max).
4. operating threshold: cost ratio c = cfg.p5.cost_ratio_miss_to_false_alarm → `t_cost = 1/(1+c)`. On validation compute, for thresholds 0.05..0.95 step 0.05, `{thr, accuracy, precision, recall, f1, cost = (c·FN + FP)/n}` (`threshold_curve`); `t_f1` = grid threshold with max F1; `t_cost_empirical` = grid threshold with min cost.
5. `metrics` (chain_check key; at t_cost) = `{threshold, accuracy, f1, roc_auc, precision, recall, pr_auc, confusion{tp, fp, tn, fn}, cost}`; `metrics_at_0_5`, `metrics_at_f1_opt` same shape; `train_metrics` at t_cost (accuracy, f1, roc_auc); `val_auc_bootstrap = {lo, hi}` (B from cfg, rng(seed), resample validation rows); `calibration = calibration_table(y_va, p_va, 10)` plus `calibration_max_gap` over bins with n ≥ 30.
6. `top_coefficients`: 15 largest |standardised weight| `[{name, weight}]`; `coef_abs_share_by_column`: share of Σ|w| by original column (via `sources`; a product splits its |w| equally among its sources).
7. foils (`label_variants`): for rules global ([]), ["workingday","hr"], and the configured rule: `{group_by, pos_train, pos_val, pos_val_2011, pos_val_2012, auc_hour_only (bias + survivor columns named hr_*; if none survive use Design(BASE) hr dummies), auc_trend_only (bias + trend, from a BASE design if trend is not a survivor), auc_full (survivor design, chosen l2), acc_full_at_0_5, majority_accuracy}`. Own `fit_logistic` for all (max_iter = cfg.p5.max_iter; record any fit that stops on max_iter in `foil_not_converged`).
8. `retrospective` = list of rows from artifacts p1..p4 and this phase: `{phase, consumed, hyperparameters (short string built from artifact values), n_features, train_score, val_score, val_rmse, extra}`: P1 (lr, iterations, val_r2, val_rmse), P2 (degree, power_cols, +wd_x_hr, gain_over_p1), P3 (anchor vs target seeded / day-block / chrono r2, label), P4 (per-method λ and val_r2, recommended, survivors count), P5 (rule, l2, threshold, accuracy, f1, roc_auc).
9. artifact `p5`, upstream "p4": features, threshold_rule, metrics + everything above + n_features, l2, l2_sweep, iterations, stop_reason, lr, weights, cost_ratio, t_cost, t_f1, t_cost_empirical.

## src/predict.py (`run(cfg=None)`; the ONLY module that uses the test frame; `python -m src.predict`)
1. `p4 = read_artifact("p4")`, `p5` (for the hash chain), `p1` (back-transform method). `rec = p4["recommended"]`.
2. Design from p4.design_spec fitted on train_df ONLY (transforms are never refitted; AMBIGUITIES A13). Columns = `rec["feature_names"]` (the surviving columns the recommended model was fitted on; `rec["fitted_on"] == "survivors"`), selected by name, no bias column. X_tr, X_va, X_test accordingly.
3. model A (as validated): fit rec.method with rec.lambda / rec.l1_ratio on train rows (same solver settings as src/phases/p4.py: import its constants/helpers rather than copying numbers); assert max|w_A - rec.weights| < 1e-6 (the artifact is reproduced). model B (submitted): same hyper-parameters fitted on train + validation rows stacked. Back-transform factor per ARCHITECTURE §3 from each model's own fit rows.
4. `pred = from_target(b_B + X_test w_B, s_B)`; submission DataFrame = columns `instant, cnt` in the exact row order of the test file, cnt rounded to 2 decimals; write `sample_submission.csv` at the repo root (utf-8, "\n").
5. artifact `p6`, upstream "p5": `{model: {method, lambda, l1_ratio}, refit_on: "train+validation", n_fit_rows, n_test_rows, pred: {mean, median, min, max, n_below_1, n_clipped}, train_cnt_mean, a_vs_b_on_test: {corr, mean_ratio, max_abs_diff, mean_abs_diff}, profile_ratio: {min, max, cells_outside_0_4_2_5} (mean prediction / train mean per (workingday, hr) cell), daily_total_ratio: {min, max} (predicted total of each test day / mean daily total of train days in the same year-month), by_year_mean: {"0": …, "1": …}}`.
