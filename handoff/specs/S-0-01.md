Print each tool's last 15 lines; exit 1 if pytest, leak_scan or chain_check failed;
  * nb: render `{{...}}` placeholders of every `nb/p*.py` into `build/nb/` with `tools/number_trace.py render` (one call per file), then `tools/build_nb.py --src build/nb --execute --out rush_hour.ipynb --timeout 3600`;
  * report: number_trace render report/report.template.md → report/report.md, then `python -X utf8 report/build_pdf.py` if that file exists;
  * verify = verify-fast + nb + submission_check + number_trace render/check on the report + `req_check --strict`;
  * submission: `python -X utf8 -m src.predict`; fingerprint: tools/fingerprint.py artifacts.
