## Phase 1 (`src/phases/p1.py`; step functions + `run(cfg=None)`; H4: numpy + own src only, no sklearn import in this file)
1. cfg, seed, `train_df, val_df = seeded_split(load_train(cfg), seed)`; `design = Design(DesignSpec(base=BASE)).fit(train_df)`; X_tr, X_va; z = log1p(cnt).
2. `lam = lambda_max(X_tr)`, bound = 2/lam, lr = cfg.p1.lr_fraction_of_bound × bound; condition number of XᵀX/n.
3. lr sweep: for each fraction in cfg.p1.sweep_fractions run GD from zeros with max_iter = sweep_max_iter, record `{fraction, lr, stop_reason, iterations, loss_final, loss_curve}` (curve subsampled to ≤ 200 points as [[iteration, loss], …]; non-finite losses stored as null and the curve cut at divergence).
4. main run: GD from zeros, lr, tol_loss, tol_grad, max_iter from cfg → weights, iterations, stop_reason, loss curve (subsampled ≤ 300 points), grad_norm_final. gradient_check at the final weights and at zeros (store the max).
5. oracle (test only, labelled so): `np.linalg.lstsq(X_tr, z)` → `oracle = {max_abs_weight_diff, loss_gap, val_r2_diff}`.
6. back-transform: for each method in cfg.p1.backtransform_candidates compute factor (train), val_r2, val_rmse, val_mean_ratio (mean prediction / mean cnt); choose max val_r2 (tie → first in list). Store `backtransform = {method, factor, candidates{…}}`.
7. scores with the chosen method: train_r2, train_rmse, val_r2, val_rmse, train_r2_log, val_r2_log; `val_bootstrap = {lo, hi, se}` (seed = team seed).
8. `residual_profile` on TRAIN rows, log-scale residual z − eta: `by_wd_hr` = [{workingday, hr, mean_resid, n}] (48 cells); `by_temp_bin`, `by_hum_bin` = 10 equal-count bins [{lo, hi, mean_resid, n}].
9. `hour_encoding_ablation`: same pipeline (own GD, same lr rule, from zeros) with the 23 hour dummies replaced by (a) numeric `hr` (one standardised column) and (b) six harmonics sin/cos(2πk·hr/24), k = 1..6 (12 columns); build these two small designs locally in p1.py with train-only standardisation. Store `{one_hot: {n_features, val_r2}, numeric: {…}, harmonics6: {…}}`.
10. bonus (src/gd_asym): `fit_asymmetric(X_tr, cnt_tr, w0 = main weights, k, max_iter, tol_loss)`; gradient check of asym loss at w0. Store `bonus = {k, stop_reason, iterations, gradient_check, train_loss_at_mse_weights, train_loss_final, val: {mse_model: operator_costs + r2 + rmse + mean_pred, asym_model: same}, mean_shift_ratio (mean asym prediction / mean mse prediction on val), by_wd_hr_shift: [{workingday, hr, mean_pred_mse, mean_pred_asym}]}`. For this comparison both models use yhat = exp(Xw) − 1 (no factor), clipped at 0.
11. artifact `p1` (upstream None). chain_check keys verbatim: weights, feature_names (= design.names), scaler (= design.scaler_dict()), lr, iterations, stop_reason, train_loss_final (float, full precision: mse_loss(X_tr, z, weights)), val_r2, val_rmse, target_transform = "log1p". Plus everything above and: design_spec, lambda_max, lr_bound, lr_fraction, condition_number, tol_loss, tol_grad, max_iter, grad_norm_final, gradient_check, loss_curve, lr_sweep, n_train, n_val, n_features.

## Phase 2 (`src/phases/p2.py`; H4 as above)

2. helper `fit_expanded(spec)`: `Design(spec).fit(train_df, base_scaler=p1["scaler"])`; assert its first 36 names == p1.feature_names; `w0 = lift_weights(p1.weights, p1.feature_names, design.names)`; `init_loss = mse_loss(X_tr, z, w0)`; assert |init_loss − p1.train_loss_final| ≤ 1e-9; lr = cfg.p2.lr_fraction_of_bound × 2/lambda_max(X_tr); GD from w0 → dict(spec, n_features, lambda_max, lr, iterations, stop_reason, init_loss, train_loss_final, train_r2, train_rmse, val_r2, val_rmse, weights).
3. degree sweep: blocks = cfg.p2.blocks, power_cols = the widest candidate list, degree ∈ cfg.p2.degree_candidates → `degree_sweep` rows (without weights). Chosen degree = smallest degree with val_r2 ≥ best − plateau_tol.
4. power-column sweep at the chosen degree over cfg.p2.power_col_candidates → `power_col_sweep`; chosen = the candidate with the fewest columns with val_r2 ≥ best − plateau_tol. (If chosen degree is 1 skip and use ().)
5. block ablation at the chosen degree/columns: without `wd_x_hr` → `block_ablation = {without_wd_x_hr: {n_features, val_r2, train_r2, iterations}}`.
6. final model = the chosen spec's run. Oracle gap (lstsq) as in P1. `val_bootstrap`. `residual_profile` as in P1 step 8 (same bins definition, recomputed). `paired_vs_p1 = paired_bootstrap_delta_r2(cnt_val, pred_p2, pred_p1)` (P1 predictions recomputed from p1 weights).
