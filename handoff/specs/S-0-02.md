algorithm:
- gd.py exactly per ARCHITECTURE §6. numpy only (no sklearn, no scipy). `GDResult` is a dataclass; `loss_history` a list of floats recorded every `record_every` iterations (index 0 = initial loss). One loop, no hidden state; the update is `w = w - lr * grad_fn(w)`.
- poly.py: `lift_weights` per §6.
- gd_asym.py (bonus R12, ADR-008). Model on the bike scale: `yhat_i = exp(x_i·w) - 1` (x has the bias column; same design as Phase 1). Residual r_i = yhat_i − y_i (y = cnt). Cost weight c_i = k if r_i < 0 (under-prediction) else 1.
  * `asym_loss(X, y, w, k=3.0)` = (1/n) Σ c_i r_i²
  * `asym_grad(X, y, w, k=3.0)` = (2/n) Xᵀ (c ⊙ r ⊙ exp(Xw))      (chain rule through exp; the weight switch has zero derivative because r=0 at the switch)
  * `fit_asymmetric(X, y, w0, k=3.0, max_iter=20000, tol_loss=1e-10, t0=1e-3) -> GDResult`: gradient descent with backtracking (Armijo) step: try step t; while L(w − t g) > L(w) − 1e-4·t·‖g‖²: t ← t/2; accept; next iteration starts from 2t. Stop `converged` when relative loss change ≤ tol_loss for 10 consecutive iterations, else `max_iter`. Clip the exponent argument to ≤ 20 for safety.
  * `operator_costs(y, yhat, k=3.0) -> dict(sq_cost, abs_cost, under_share, mean_error)`: sq_cost = mean(c r²), abs_cost = mean(k·max(−r,0) + max(r,0)), under_share = mean(r < 0), mean_error = mean(r).
constraints: H4 (no sklearn/scipy in these files), float64, deterministic, no `.predict(` / `.fit(` attribute calls in these files (leak_scan L3). Docstrings state the formula; code must be readable by a student (short functions, names match the math).
acceptance (throwaway checks; qa writes tests/ independently):

  - On a random well-conditioned problem GD with lr = 1/λ_max converges, `stop_reason == "converged"`, max|w − lstsq| < 1e-5; lr = 1.05·2/λ_max → `diverged`; lr = 1e-4·2/λ_max with max_iter=500 → `max_iter`.
  - loss_history is monotonically non-increasing for lr ≤ 1/λ_max.
  - fit_asymmetric on synthetic log-linear data lowers asym_loss versus w0 = least-squares-in-log weights and raises mean prediction (under_share falls below 0.5).
