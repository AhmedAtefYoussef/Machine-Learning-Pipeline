algorithm:
- Objective (sklearn scaling, must match exactly): J(b, w) = (1/2n)‖y − b − Xw‖² + α·ρ‖w‖₁ + (α/2)(1 − ρ)‖w‖². X: (n, p) without bias column. Functions centre X columns and y internally and return b = ȳ − x̄·w, so they are correct for any X (not only pre-centred).
- `ridge_closed_form(X, y, alpha)`: solve (XcᵀXc/n + αI) w = Xcᵀyc/n with `np.linalg.solve` (ρ = 0 case; equals sklearn `Ridge(alpha=n·α)`).
- `enet_cd(X, y, alpha, l1_ratio, w0=None, tol=1e-9, max_sweeps=5000)`: cyclic coordinate descent with covariance updates. Precompute G = XcᵀXc/n (p×p), c = Xcᵀyc/n. Maintain q = G w. Per coordinate: z_j = c_j − q_j + G_jj w_j; w_j ← S(z_j, αρ) / (G_jj + α(1 − ρ)); update q += G[:, j]·Δ. S(z, t) = sign(z)·max(|z| − t, 0). A column with G_jj = 0 keeps w_j = 0. Stop when max_j|Δw_j| < tol in a full sweep. Return (b, w, sweeps). Optional args `G=None, c=None` to reuse precomputed Gram across a path.
- `alpha_max(X, y, l1_ratio)` = max|c| / ρ (ρ > 0). `alpha_grid(a_max, min_ratio, n)` log-spaced descending.
- `enet_path(X, y, alphas_desc, l1_ratio) -> (B (len,), W (len, p), sweeps (len,))` warm-started along descending α, Gram computed once.
- `ridge_path(X, y, alphas) -> (B, W)` via one eigendecomposition of G.
- `stability_selection(X, y, alpha, l1_ratio, groups, seed, B=50) -> freq (p,)`: for b in range(B): rng = default_rng(seed + b); draw unique groups with replacement (same count), take all rows of each drawn group (with multiplicity); re-standardisation is NOT done (X already standardised); fit enet_cd; freq_j = share of resamples with |w_j| > 1e-10.
- logistic.py per ARCHITECTURE §7. X HAS a bias column (col 0, unpenalised). L(w) = −(1/n)Σ[y log p + (1−y) log(1−p)] + (l2/2)‖w[1:]‖², computed stably via `np.logaddexp(0, ±η)`; ∇ = (1/n)Xᵀ(p − y) + l2·[0, w[1:]]. `fit_logistic` starts from zeros, default lr = 1/(λ_max(XᵀX/n)/4 + l2), delegates to `gd.gradient_descent`. Metrics implemented with numpy only: `roc_auc` (Mann-Whitney with average ranks), `pr_auc` (average precision: Σ (R_k − R_{k−1}) P_k over descending score thresholds), `confusion(y, p, thr) -> dict(tp, fp, tn, fn)`, `prf(y, p, thr) -> dict(accuracy, precision, recall, f1)`, `calibration_table(y, p, bins=10) -> list[dict(lo, hi, n, mean_p, frac_pos)]` (equal-width bins).
