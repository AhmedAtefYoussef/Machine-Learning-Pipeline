## src/phases/p3.py  (`run(cfg=None)`; step functions)
1. `p2 = read_artifact("p2")`, `p1 = read_artifact("p1")` (back-transform method only). Split as always. `anchor_spec = DesignSpec.from_dict(p2["design_spec"])`.
2. ladder specs from cfg.p3.ladder, cumulative: level i blocks = union of all `add` up to i. Levels before the `phase2: true` level use degree 1 and no power columns (C0 additionally removes hr_1..hr_23 from base; C1 = BASE; C2 = BASE + listed blocks); the `phase2` level IS anchor_spec exactly (assert its blocks ⊇ the blocks accumulated so far); later levels = anchor_spec + accumulated blocks (degree and power_cols of the anchor).
3. for every level: `three_validators` → row `{name, index, blocks, n_features, seeded{train_r2, train_rmse, r2, rmse}, day_block{train_r2, r2, sd, folds}, chrono{train_r2, r2, rmse}, gap_seeded (train − val)}`. Assert the anchor level's seeded r2 equals p2["val_r2"] within 2e-3 (GD vs closed form) and store the difference as `anchor_check`.
4. degree axis: anchor blocks and power_cols, degree ∈ cfg.p3.degree_axis → same row shape (`degree_axis`).
5. target level = argmax seeded r2 over ladder levels (tie → lower index). Also store `best_level_day_block`, `best_level_chrono`, and `overfit_from_level` = first level above the target whose seeded r2 is ≥ 0.002 below the target's while its seeded train_r2 is higher (null if none).
6. `paired_target_vs_anchor` = paired_bootstrap_delta_r2 on seeded validation predictions (target vs anchor). `val_bootstrap_anchor`, `val_bootstrap_target` = bootstrap_r2.
7. learning curves for anchor, target and the top ladder level: `learning_curve(spec, …, cfg.p3.learning_fractions, seed)` → `[{fraction, n_days, n_rows, train_r2, val_r2}]`; subsets are nested prefixes of ONE permutation of the training dates drawn with default_rng(seed).
8. chronological detail for anchor and target: `{cut_date, n_early, n_late, mean_cnt_early, mean_cnt_late, r2, rmse, mean_ratio (mean pred / mean cnt on late), r2_level_corrected}` where r2_level_corrected rescales late predictions by mean cnt / mean pred of the LATE period (diagnostic of level drift only; labelled as not a usable estimate).
9. `noise_floor(train_df)`.
10. `estimates` (chain_check key) = for the ANCHOR: `{seeded: {r2, rmse, train_r2, lo, hi}, day_holdout: {r2, sd, train_r2}, chrono: {r2, rmse, train_r2}}`; `estimates_target` same for the target; `gaps = {anchor: {leakage: seeded − day_holdout, drift: day_holdout − chrono}, target: {…}}`.
11. `diagnosis` = `{label, anchor_gap_train_val, gain_target_over_anchor, gain_ci_lo, gain_ci_hi, day_block_gain, chrono_gain, degree_axis_range (max − min seeded r2 over degrees ≥ 2), overfit_from_level}`; label rule: "under-fit" if target index > anchor index and gain_ci_lo > 0 and day_block_gain > 0; "over-fit" if target index < anchor index and the same test holds in that direction; else "reasonably fit".
12. `target_complexity` (chain_check key) = `{level, index, n_features, degree, power_cols, blocks, design_spec}`; `anchor = {degree, power_cols, blocks, n_features, feature_names_sha256 (sha256 of "\n".join(p2.feature_names)), p2_val_r2}`. Artifact `p3`, upstream "p2". Also store cut_date, k folds, fit_alpha.
